# AltSearch Links

Userscript that adds an **Alt Search** dropdown to search results pages so you can rerun your current query on a different search engine. On Bing it also adds a "Try this search on…" line above the page numbers.

**Works on:** Google, Google Scholar, Bing, DuckDuckGo, Swagbucks

**Alternate engines:** Google, Bing, Yahoo, DuckDuckGo, WolframAlpha, Google Scholar, Wikipedia, Reddit, GitHub, Mojeek, Karma. The engine you're already on is left out of the list.

## Install

- From Greasy Fork: https://greasyfork.org/en/scripts/13542-altsearch-links
- Or, with Tampermonkey or Violentmonkey installed, open the raw [altsearch.user.js](../../raw/master/altsearch.user.js) and confirm the install.
